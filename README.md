# Сайт вакансий

Небольшой сайт с вакансиями и формой отклика на **FastAPI**.

## Возможности

- Список открытых вакансий
- Форма заявки: ФИО, телефон, специальность, опыт, возраст, наличие прав — с проверкой полей на сервере
- Уведомление на почту о каждой новой заявке
- Согласие на обработку персональных данных и политика конфиденциальности (152-ФЗ)
- Админка с входом по паролю:
  - добавление и редактирование вакансий
  - скрытие неактуальных вакансий без удаления
  - просмотр всех заявок

## Технологии

Python, FastAPI, Jinja2, SQLite, Pydantic, HTML/CSS

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
uvicorn main:app --reload
```

Сайт: http://127.0.0.1:8000, админка: http://127.0.0.1:8000/admin

## Настройки

| Переменная окружения | Зачем | По умолчанию |
|---|---|---|
| `ADMIN_PASSWORD` | Пароль админки | `admin` (только для разработки!) |
| `SECRET_KEY` | Ключ подписи cookie сессии | случайный при каждом запуске |
| `EMAIL_MODE` | `console` — печатать письма в консоль, `smtp` — отправлять | `console` |
| `EMAIL_TO` | Кому слать уведомления о заявках (через запятую) | `hr@example.ru` |
| `SMTP_HOST`, `SMTP_PORT` | Почтовый сервер | `smtp.yandex.ru`, `465` |
| `SMTP_USER`, `SMTP_PASSWORD` | Логин и пароль приложения почты | — |
| `SITE_URL` | Адрес сайта для ссылок в письмах | `http://127.0.0.1:8000` |
